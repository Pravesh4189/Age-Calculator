# 🎂 Age Calculator

A simple and responsive **Age Calculator** built using **HTML, CSS, and JavaScript**.

This application calculates a user's exact age based on their date of birth and the current date.

## 🌐 Live Demo

👉https://age-calculator-eight-lac.vercel.app/

## 🚀 Features

- 📅 Select date of birth
- 🎂 Calculates current age
- 📊 Displays age in years, months, and days
- ⚡ Fast and easy to use
- 📱 Responsive design
- 🎨 Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How It Works

1. Select your date of birth.
2. Click on the **Calculate** button.
3. JavaScript calculates the difference between your date of birth and the current date.
4. Your age is displayed in years, months, and days.
